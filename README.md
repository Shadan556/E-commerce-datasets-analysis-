Amazon E-commerce Data Analysis 
 In this project, I have taken Amazon e-commerce datasets from Kaggle for analysis. The dataset         includes multiple files such as:

 .Amazon Sales Report
 .Cloud Warehouse Comparison Chart
 .International Sales Report
 .Expense IIGF
 .May 2022 Data
 .P&L March 2021
 .Sales Report 2021

- Objective

The main objective of this project is to analyze e-commerce sales data and understand business performance using Python.

-Tools & Technologies Used

1.Python
2.pandas
3.numpy
4.matplotlib
5.seaborn
6.Jupyter Notebook

- Steps Performed
1.Loaded and explored the datasets
2.Cleaned the data by handling missing values and duplicates
3.Converted date columns into proper format
4.Performed data analysis using groupby and aggregation
5.Created pivot tables and crosstab for better understanding
6.Calculated important KPIs like revenue, orders, and average order value
7.Visualized data using charts

-Key Metrics
1.Total Revenue
2.Total Orders
3.Total Units Sold
4.Average Order Value

-Key Insights
1.Some states and cities generate higher revenue than others
2.A few product categories contribute most of the sales
3.Cancellation rate affects overall business performance
4.Zero-value orders indicate possible cancellations or data issues

-Conclusion

This project helps in understanding sales trends and business performance.
The insights can be used to improve decision-making and increase revenue.
